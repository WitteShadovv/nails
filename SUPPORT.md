# Support

## Getting Help

- **Bug reports:** [GitHub Issues](https://github.com/WitteShadovv/nails/issues) using the bug report template
- **Feature requests:** [GitHub Issues](https://github.com/WitteShadovv/nails/issues) using the feature request template
- **General questions:** [GitHub Discussions](https://github.com/WitteShadovv/nails/discussions)

## Security Vulnerabilities

**Do not** report security vulnerabilities through public issues or discussions.

See [SECURITY.md](SECURITY.md) for private disclosure instructions. Contact: security@nails.run

## Before Reporting

1. Check existing issues and discussions for your question
2. Run `nails status -v` and `nails verify` to gather diagnostic information
3. Include your NixOS version, NAILS version (`nails --version`), and hidden volume configuration
